MinorUPI Integration Guide

MinorUPI is your private, single-admin UPI payment gateway. It provides direct peer-to-peer UPI payments with zero payment aggregator transaction cuts, automatic FamApp email receipt verification, unique paise offset mapping, and cryptographic webhook callbacks.

Authentication

All private API endpoints require an API Key passed via header. You generate API keys from the MinorUPI Dashboard under the API tab.

X-API-Key: mupi_live_your_secret_key_here
# Or standard bearer header:
Authorization: Bearer mupi_live_your_secret_key_here

Create Order

Create a payment request for a specific amount in INR. MinorUPI automatically assigns an available paise offset (e.g. ₹50.00 -> ₹50.01) to distinguish multiple simultaneous transactions.

POST /api/v1/orders
Content-Type: application/json
X-API-Key: <YOUR_API_KEY>

{
  "amount": 50.00,
  "order_id": "ORD_1001",
  "callback_url": "https://yourwebsite.com/api/payment-webhook",
  "redirect_url": "https://yourwebsite.com/checkout/success",
  "expiry_minutes": 5,
  "note": "Pro Tier Subscription"
}

Webhook Verification (HMAC-SHA256)

When customer payment is verified via FamApp notification, MinorUPI sends an instantaneous POST request to your callback_url with header X-Signature containing the HMAC-SHA256 hex digest of the raw body signed with your Webhook Secret.

# Python (Flask / FastAPI)
import hmac, hashlib

def verify_webhook(raw_body_bytes, signature_header, webhook_secret):
    expected = hmac.new(webhook_secret.encode(), raw_body_bytes, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature_header)
